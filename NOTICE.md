# SuperMail

SuperMail is a modified version of **Mailflare** by Hieu Nguyen
(https://github.com/hieunc229/mailflare-macos), changed by Roman Pathak from November 2026.

Like Mailflare, SuperMail is free software under the GNU Affero General Public License v3
(see `LICENSE`). Anyone who receives SuperMail may get its complete source, including every change,
from https://github.com/romanpathak111/mailflare-macos. SuperMail is not made, endorsed or supported by
the Mailflare authors.

Main changes from Mailflare:
- The assistant runs through Claude Code or Codex on the user's Mac, with no API key.
- Status board, status lists, Today, and the SuperMail design.
- Suggested statuses and folder rules learned from the user's own filing.
- Use of the MCP servers already set up in Codex or Claude Code.
- New name and icon; updates come from the SuperMail repository.
